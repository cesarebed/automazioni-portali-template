# Learnings per-portale

Un file per portale onboardato, es. `<portale>.md`. Il file nasce durante l'onboarding
(skill `onboarding-portale`) e raccoglie i gotcha specifici di quel portale. Gli id
`[L-nnn]` sono globali e unici sull'unione di tutti i file dei learnings (vedi il
protocollo in `data/learnings.md`).
